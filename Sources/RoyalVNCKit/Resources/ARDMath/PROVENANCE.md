# ARDMath provenance

The CS_BigInt sources are copied without algorithm changes from royalapplications/CryptoSwift, revision a59b4d91ebb22011656c830f874fe7152e183a57. Original copyright notices are retained. CryptoSwift derives this big-integer implementation from Károly Lőrentey’s BigInt. Both licenses are bundled here. This product includes software developed by the "Marcin Krzyzanowski" (http://krzyzanowskim.com/).

RemoteLah builds these same sources as the private ARDMath target with optimization enabled in Debug as well as Release. Only RoyalVNC BigNum switches its import; authentication algorithms, key sizes and randomness are unchanged.
